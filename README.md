# Claude Skills

Claude skills I built as a product marketer to speed up everyday marketing work: visuals, emails, changelogs, launches and content reviews.

Each skill is a folder with a `SKILL.md` (the instructions Claude follows) and a `README.md` (what it does and how to make it yours). The examples use **Example Feedback**, a fictional customer feedback platform, with placeholder colors, names and links. Swap in your own before you use them.

## How to use a skill

1. Copy a skill folder from `skills/` into your Claude skills folder (or upload it as a skill in Claude).
2. Replace the placeholders listed under "Make it yours" in that skill's README.
3. Ask Claude for the task the skill describes. It triggers on its own.
