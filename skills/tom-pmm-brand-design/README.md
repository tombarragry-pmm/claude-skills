# tom-pmm-brand-design

Tool-agnostic brand rules for any visual: colors with exact hex values, approved color combinations, typography rules, logo rules, design principles and on-screen copy rules. It works the same whether the output is HTML, SVG, React, Remotion or a slide.

Originally built: November 2026

## What it does

1. Gives Claude exact color values and the approved dark, light and accent scene combinations.
2. Sets typography and logo rules, including which logo variant goes on which background.
3. Applies do and don't design principles before a visual is finalized.
4. Keeps on-screen text short, outcome-led and free of banned words.

## Files

- `SKILL.md`: the instructions Claude follows.

## Requirements

- None. The Figma connector helps if you want Claude to check values against your design system file.

## Make it yours

The colors are a neutral placeholder palette for Example Feedback, a fictional customer feedback platform. Replace them, the product names, the type scale reference and the design system link with your own.
