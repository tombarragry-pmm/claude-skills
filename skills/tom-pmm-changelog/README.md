# tom-pmm-changelog

Writes short, factual posts for a public product changelog: a descriptive title, a direct body, a "Why it matters" section and optional bullets.

Originally built: November 2026

## What it does

1. Collects a brief: the change, the surfaces it affects, the "why it matters" angle and any screenshot.
2. Drafts the full post using a fixed structure and title patterns.
3. Presents the whole draft for review in one go.
4. Iterates on title wording, "why it matters" framing or bullets, then outputs clean markdown ready to paste.

## Files

- `SKILL.md`: the instructions Claude follows.

## Requirements

None.

## Make it yours

The examples use Example Feedback, a fictional customer feedback platform. Replace the changelog URL, the product surfaces and area names, and the three reference examples with real posts from your own changelog.
