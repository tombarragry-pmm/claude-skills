# tom-pmm-email-creation

Writes copy, produces graphics and builds drafts in Customer.io for product marketing emails: monthly product updates, special editions, webinar invites, event invites and onboarding sequences.

Originally built: November 2026

## What it does

1. Runs a short intake: email type, broadcast or campaign, audience and key content.
2. Drafts the copy in chat using a fixed structure for each email type, and waits for approval.
3. Produces graphics for product update emails, using UI close-ups or illustrative explainers.
4. Builds the template in Customer.io through the Customer.io connector, and links you to it for review.

## Files

- `SKILL.md`: the instructions Claude follows.

## Requirements

- The Customer.io connector, for Step 5. Note that it only supports Design Studio templates, not rich text emails.

## Make it yours

The examples use Example Feedback, a fictional customer feedback platform. Replace the product areas, URLs, sender details, taglines and accent colors with your own.
