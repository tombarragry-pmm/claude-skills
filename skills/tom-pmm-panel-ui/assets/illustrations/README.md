# Illustrations

Put your product's empty-state and confirmation illustrations here as SVG files, in folders by area. For example: `dashboards/empty-state.svg`.

In a mockup, write `<div class="illustration" data-illustration="dashboards/empty-state"></div>`. `render_screen.py` inlines the matching SVG. If the file doesn't exist, the render warns you and shows a placeholder block in the accent tint.

This folder ships empty. Use your own design team's artwork, never invented clip art.
